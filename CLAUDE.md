# VxHub for Android

The Android port of the VxHub iOS SDK (`../VxHub - iOS`, github.com/ersel95/VxHub-iOS), released
through JitPack from this repository's tags as `com.github.ersel95.VxHub-Android:<module>:<tag>`.

- **Developing it:** read `AGENTS.md` first: layout, commands, toolchain, the behaviours that must
  stay in step with iOS, porting newer iOS work, releasing, known follow-ups.
- **Integrating it into an app:** `INTEGRATION.md`; `sample/` is a working host app.
